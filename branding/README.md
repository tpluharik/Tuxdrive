# TuxDrive visual identity

The TuxDrive mark is an original black-and-white penguin head with a geometric amber beak. It is designed to remain recognizable in Ubuntu launchers, window chrome, notifications, and the system tray.

- `tuxdrive-logo.png` is the high-resolution transparent master.
- `packaging/tuxdrive.svg` is the scalable application and repository icon.
- Sync and error variants add blue activity and red attention badges.
- All eight supported cloud services retain provider-specific colors in account-selection screens. Direct peer folders use a network identity, while encrypted vaults use a protection/lock identity so they cannot be mistaken for their backing provider.

The TuxDrive artwork is distributed under the repository's MIT license. Cloud-service names and visual identifiers belong to their respective owners; their appearance only identifies interoperability.
