# Android releases

The installable APK is published as a GitHub Release asset. `latest-v2.json`
is the stable Android auto-update channel and is signed offline with the
TuxInDrive update key after CI produces the package.

The durable APK for version `VERSION` is:

`https://github.com/tpluharik/Tuxindrive/releases/download/vVERSION/TuxInDrive-VERSION-android.apk`
