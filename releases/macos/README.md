# macOS releases

The installable DMG is published as a GitHub Release asset. `latest-v2.json`
is the stable macOS auto-update channel consumed by Settings → Check for
updates. The downloaded image is opened only after signature and SHA-256
verification.

The durable Apple Silicon image for version `VERSION` is:

`https://github.com/tpluharik/Tuxindrive/releases/download/vVERSION/TuxInDrive-VERSION-macos-arm64.dmg`
