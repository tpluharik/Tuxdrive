# Windows releases

The x64 installer and portable ZIP are published as GitHub Release assets.
`latest-v2.json` is the stable Windows auto-update channel consumed by
Settings → Check for updates. The installer is opened only after signature
and SHA-256 verification.

The durable installer for version `VERSION` is:

`https://github.com/tpluharik/Tuxindrive/releases/download/vVERSION/TuxInDrive-VERSION-windows-x64-setup.exe`
